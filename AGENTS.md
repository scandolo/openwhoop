# OpenWhoop: guide for contributors and coding agents

TypeScript end to end. The Node server runs `.ts` directly (type stripping, no
build step). The web app is React + Vite. Storage is `node:sqlite`. The only
runtime dependencies are `hono`, `@hono/node-server` and `zod`.

## Commands

```bash
npm run dev          # server :8787 (--watch) + Vite :5173 with /api proxy
npm run demo         # seed ./data-demo with simulated weeks, then serve it
npm test             # vitest: protocol, algorithms, pipeline, API
npm run typecheck    # tsc (TypeScript 7)
npm run build        # web app → dist/web
npm run check        # all of the above
npm run calibrate -- <dir-with-whoop-exports> [--write]   # refit score constants
```

## Conventions

- **Node runs TypeScript directly.** Use only erasable syntax: no enums (use
  `as const` objects), no parameter properties, no namespaces. Relative
  imports carry the `.ts`/`.tsx` extension, and type-only imports use
  `import type`.
- **Server code must not import `src/web`.** Shared code lives in
  `src/protocol` and `src/algorithms`, and both run in the browser too (no
  Node APIs there).
- **Algorithms are pure.** Constants that come from data belong in
  `calibration.ts` via `npm run calibrate`, not hand edits. When you change a
  model, update docs/algorithms.md and tag each claim **published**,
  **fitted** or **design**.
- **Never acknowledge a history batch before the server has stored it.**
  Companion mode never acknowledges at all (see docs/protocol.md §3).
- **Raw frames are archived.** If you improve a decoder, `reprocessRaw()` in
  `ingest.ts` re-decodes everything stored.
- **UI:** design tokens live on `:root` in `styles.css`. Color only carries
  meaning: recovery bands, strain blue, sleep steel blue, stress. Charts are
  hand-written SVG in `components/charts.tsx` and measure their real width so
  labels stay legible.
- **Tests:** protocol tests use the real captures in `protocol.test.ts`.
  Pipeline tests run the simulator end to end. Keep `npm run check` green.

## Gotchas

- There is no strap in CI. Exercise sync logic against the simulator, or with
  recorded frames through `/api/ingest`.
- The strap allows one Bluetooth central at a time. It offloads about 10
  records per second.
- Skin temperature and SpO₂ fields are disputed or unusable on 4.0; see
  docs/protocol.md §4 before using them.
- The WHOOP and Strava integrations need a public `https` URL for OAuth when
  hosted (`PUBLIC_URL`).
